### [Diagnosta – PC Checker](https://github.com/Tyzoo7/diagnosta)
Finds out why a Windows PC is slow or unstable and explains it in plain language.
Checks system, drives, battery, network, startup apps and running programs, and creates
an anonymised support report to attach to a ticket. Read-only, no admin rights, no telemetry.

🛠️ `C#` `.NET 10` `Spectre.Console` `Windows` `Terminal`
